# 📦 База сниппетов для надстройки Macro Tools VBA

> Коллекция готовых фрагментов кода VBA для ускорения разработки в среде Excel.

Этот репозиторий содержит библиотеку сниппетов, предназначенных для работы с надстройкой [Macro Tools VBA](https://github.com/vbatools/Addin_MacroToolsVBA). Сниппеты автоматически синхронизируются с репозиторием, обеспечивая мгновенный доступ к проверенным шаблонам кода.

---

## 📖 Назначение

База сниппетов расширяет функционал надстройки **Macro Tools VBA**, предоставляя разработчикам:
- ✅ Готовые шаблоны для типовых задач VBA
- ✅ Автоматическую подгрузку обновлений из репозитория
- ✅ Удобную категоризацию по областям применения
- ✅ Поддержку автодополнения и быстрого поиска

---

## 🛠️ Настройка и импорт сниппетов

Для работы со сниппетами выполните следующие шаги:

1. Откройте панель инструментов надстройки **Macro Tools VBA**
2. Перейдите в раздел **Other tools**
3. Выберите необходимую операцию:

| Действие | Описание |
|----------|----------|
| 📂 **Export Snippets to Folder** | Экспортирует все сниппеты из надстройки в локальную папку `ADDIN_MACRO_TOOLS_SNIPPETS` с сохранением структуры категорий |
| 📄 **Add local JSON from Folder** | Генерирует единый JSON-файл из экспортированных папок сниппетов |
| 📄 **Import Snippets from local JSON** | Импортирует сниппеты из локального JSON-файла, созданного предыдущим инструментом |
| 🌐 **Import Snippets from GitHub** | Загружает актуальную версию базы сниппетов напрямую из этого репозитория *(внимание: существующие сниппеты будут заменены)* |

---

## 💻 Использование сниппетов в коде

1. Откройте редактор VBA (`ALT + F11`) и перейдите в целевой модуль
2. Начните вводить название сниппета (например, `pusub`, `arr`, `LastRow`)
3. В контекстном меню выберите **Insert Code**
4. ✅ Код автоматически вставится в модуль; связанные формы и модули подключатся при необходимости

### ⚡ Горячие клавиши
- `ALT + Z` — быстрый вызов вставки сниппета *(требуется установленный модуль [MacroToolsVBAHotKeys](https://github.com/vbatools/MacroToolsVBAHotKeys))*

> 💡 **Совет:** Если название сниппета забыто, воспользуйтесь инструментом **Insert Module** на панели VBE. Будет создан служебный модуль `SNIPPETS` с полным каталогом доступных шаблонов и описаний. После его добавления активируется автодополнение (например, `SNIPPETS.App.prsub`).  
> Модуль `SNIPPETS` можно в любой момент удалить через кнопку **Delete Module**.
